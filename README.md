How to run it

On the GitHub repo page, click the green Code button, then Download ZIP.
Extract (unzip) the ZIP file.
Open VS Code, go to File → Open Folder, and pick the extracted folder.
Open the terminal in VS Code (Terminal → New Terminal).
Type npm install and press Enter. Wait for it to finish.
Type npm start and press Enter.
Open http://localhost:8000/ in your browser.
